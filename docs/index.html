从 Claude 页面迁移批注

如果你之前在 Claude 生成的页面（claude.ai/artifact/…）上已经写过批注， 那些数据存在那个页面自己的浏览器存储里，没有办法自动搬过来—— 需要手动导出、再导入一次：
  1. 打开旧的 Claude 页面，滚动到文末「我的批注 · 总览」，点击「备份 .json」下载批注文件
  2. 打开这个站点上对应的同一篇文献
  3. 同样滚动到文末，点击「导入备份 .json」，选中刚才下载的文件
导入是合并而不是覆盖——如果这篇在新站点上已经写了别的批注，不会丢。
